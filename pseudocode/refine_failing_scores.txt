Student Name: Rana Alsanousi

Problem:
Find which scores failed.

Input:
a list of student scores

Output:
the failing scores, or a message if no one failed

Failing rule:
score < 50

Pseudocode:
START
    READ the list of student scores
    CREATE an empty list called failing_scores
    FOR each score in the list of student scores
        IF score < 50
            ADD score to failing_scores
        END IF
    END FOR
    IF failing_scores is empty
        OUTPUT "No one failed"
    ELSE
        OUTPUT failing_scores
    END IF
END
