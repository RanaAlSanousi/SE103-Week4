Problem:
Search a list of names for one target name and report whether it was found.

Input:
- a list of names
- one target name

Output:
- "Found" or "Not found"
- or an error if the list is empty

Pseudocode:
START
    READ the list of names
    READ the target name
    IF the list is empty
        OUTPUT "Error: list is empty"
        STOP
    END IF
    FOR each name in the list
        IF name equals target name
            OUTPUT "Found"
            STOP
        END IF
    END FOR
    OUTPUT "Not found"
END
